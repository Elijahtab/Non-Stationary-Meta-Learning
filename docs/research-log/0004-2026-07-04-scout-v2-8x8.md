# 0004 — Autoresearch scout benchmark v1 (5×5) saturates; switch primary to `fast_switch_scout_v2` (8×8)

- **Date:** 2026-07-04
- **Status:** Accepted
- **Touches:** `src/lifelong_learning/research/benchmarking.py` (**immutable_surface** — new
  spec ADDED, `fast_switch_scout_v1` untouched), `config/research_manifest.toml` (primary),
  `src/lifelong_learning/research/trial_prompt.py` (benchmark-scoped trial history).

## Context

The first full autoresearch campaign with Claude (Fable) as the trial agent ran six trials
against `fast_switch_scout_v1` (5×5, 1 seed) on 2026-07-04. Every mechanism-family lever was
rejected, all within ~1–3% below baseline:

| Trial (session) | Hypothesis | composite | vs baseline 0.6622 |
| --- | --- | --- | --- |
| 1 (022146) | Actor-only modulation | 0.6541 | −1.2% |
| 1 (133654) | Two-sided gain mask | 0.6552 | −1.1% |
| 2 (133654) | FiLM per-channel scale+shift | 0.6470 | −2.3% |
| 3 (133654) | Separate actor/critic masks | 0.6411 | −3.2% |
| 4 (133654) | Context dim 8→16 | 0.6622 | −0.01% |
| 5 (133654) | Channel-wise gates (free pick) | 0.6507 | −1.7% |

The v1 baseline's `hit_rate_80` is **0.991** — at ceiling, echoing
[research-log 0001](./0001-2026-06-18-calibration-scoring.md)'s finding that 5×5 settings
saturate ("everyone recovers"), which is why the notes-0001/0002 science already ran on
`calib8x8`. With 25% of the composite at ceiling, variants can lose but structurally cannot
win — the scout is a biased-toward-null search instrument.

## Decision

Add `fast_switch_scout_v2`: identical config to `fast_switch_holdout_v1` (8×8, 800k steps,
100k/regime) but single-seed, as the new manifest primary. `fast_switch_scout_v1` stays
frozen and unmodified so its six verdicts remain reproducible. The scout→holdout gate
becomes a pure replication test (1 seed → 3 seeds, same task). Trial-history injection now
labels every verdict with the benchmark it was scored on, and the prompt rules scope
retirement to the current primary — so all six v1-rejected hypotheses are re-testable on v2.

## Rationale

Cost is ~neutral (wall-clock is dominated by the fixed 800k-step budget: 5×5 scout 76 min vs
8×8 holdout ~73 min/seed on the same GPU). Adding a versioned spec preserves the immutable-
benchmark contract; only the pointer in the human-owned manifest moves.

## Prediction (registered before any v2 data)

If v1's ceiling produced false negatives, at least one of the six mechanisms should score
above the v2 baseline's noise band when retried. If all of them still land at-or-below
baseline on v2, the "context-code routing is inert; scalar-HP control drives adaptation"
conclusion from notes 0001/0002 gains its strongest evidence yet.
